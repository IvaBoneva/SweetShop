# 🎂 Sweet Shop

A web app for browsing cakes, placing orders, and adding reviews.  
Built with Node.js, Express, MongoDB, and vanilla JavaScript.

## 🚀 Features

- 🍰 Browse cakes with images, prices, and descriptions  
- 🛒 Place orders with quantity and address  
- 💬 Add reviews to cakes  
- 🔒 User sessions to save customer info
- 🛠️ Admin panel to manage products and view purchases  

## ⚙️ Tech Stack

- Backend: Node.js, Express  
- Database: MongoDB with Mongoose  
- Frontend: HTML, CSS, JavaScript

## 🔧 Installation

1. Clone the repo  
2. Run `npm install`  
3. Configure your MongoDB connection in `.env` or `config` file  
4. Start the server: `npm start`

## 🔧 Usage

- Open browser at `http://localhost:3006`  
- Browse cakes and place orders  
- Add reviews on product pages
